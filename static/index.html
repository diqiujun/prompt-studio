插件（提示词模板 + 代码插件：能注册工具按钮、设置项、后端接口）

一个插件 = plugins\你的插件\plugin.json，可选 spec.md（规范正文）+ plugin.py（代码，需你点「信任并加载」才会执行）。模板插件放进去就以一张新卡片出现在「提示词撰写」；代码插件还能注册工具按钮（作用于当前结果）、设置项、后端接口 /api/plugin/<id>/…，也能挂 generate.after 钩子改写输出。格式说明见 plugins\README.md，自带示例 sample_generic（纯模板）与 sample_tools（代码插件）。

运行环境（本地模型用的 llama.cpp，按硬件自动适配）

程序自带多套预编译运行包：NVIDIA CUDA 13.5 / 12.4、AMD ROCm 10.0、CPU 通用，分 x64 与 ARM64。首次启动自动检测系统架构与显卡（驱动支持的 CUDA 版本），挑一套解压到 runtime\<包名>\；没 N 卡走 CPU、AMD 卡走 ROCm。只支持 Windows。

提示词规范（内置规范可启用 / 禁用 / 替换，可添加自己的规范）

关掉某条＝本次不注入该组件；「编辑替换」＝用你自己的内容顶掉官方原文（可一键恢复内置）；「＋ 添加规范」＝把你写的规范注入到该模板系统提示词末尾，并声明优先级高于内置规范。改动只写进 data\config.json 的 specs 段，templates\ 里的官方原文文件永不被改写。

启动与打包

端口占用时程序自动顺延端口（默认 8760）。打包 exe：pyinstaller build/promptstudio.spec，产物在 dist\PromptStudio\PromptStudio.exe。

添加自定义模型

例：想写 FLUX 的提示词，就把 FLUX 的写法要求写进「规范正文」，之后它就和内置模板一样出现在模型列表里，选它、说需求、出提示词。
