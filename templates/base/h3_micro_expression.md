# H3 微表情与情绪控制

## 一句话

**别写「他很悲伤」，写「sad micro expressions，先看着对方，然后抿嘴低头，然后用手抹一下眼睛，然后抬头说台词」。**

---

## 第一招：锚定词 `micro expressions`

把 `micro expressions` 跟在情绪词后面。

| 写法 | 得到的效果 |
|---|---|
| `sad` | 一张悲伤的脸，幅度大、恒定、像贴图 |
| `sad micro expressions` | 淡淡的悲伤，只在眉、眼、嘴角起微小变化 |
| `cold micro expressions` | 冷，不是凶，是没什么反应的那种冷 |
| `suppressed anger micro expressions` | 压着的怒，咬肌、鼻翼、眉根，不外放 |
| `contempt micro expressions` | 轻蔑，一边嘴角，眼睛不跟着笑 |

要点：

- **情绪词必须在前面**，`micro expressions` 是修饰，不是主体。
- 一个镜头**只给一个情绪词**。给两个（`sad and angry micro expressions`）模型会折中成一张没有情绪的脸。
- 加程度词会更淡：`faint / barely / held-down / a hint of`。做「压着不说」的戏就靠这个。

---

## 第二招：明确部位 + 明确顺序

按顺序写清**哪个部位、做什么动作、要体现什么**，最后落到台词或定格。

作者原例（`sad micro expressions`）：

> 首先是看着对方，然后是抿嘴唇低下头，然后快速用手抹眼泪，然后抬头，说台词。

拆开看，它给了模型四件事：

1. **起点**（看着对方）——确定视线与关系
2. **抑制**（抿嘴唇低下头）——情绪被压回去，这是「微」的来源
3. **泄露**（快速抹眼泪）——一个具体动作，把情绪外化
4. **复位**（抬头，说台词）——回到可继续的表演状态

### 可直接套的模板

```
（情绪词 + micro expressions）。先<起点动作>，然后<抑制动作>，然后<泄露动作>，最后<复位动作>，开口说台词。
```

### 按情绪填表

| 情绪 | 起点 | 抑制 | 泄露 | 复位 |
|---|---|---|---|---|
| 压着的悲 | 看着对方 | 抿嘴、下颌收紧、眼皮垂下 | 喉结动一下、吸一口气没吸满 | 抬眼，说话 |
| 压着的怒 | 盯着对方 | 咬肌绷起、鼻翼微张、嘴唇抿成一条线 | 手指在身侧收紧一下 | 松开下颌，说话 |
| 讥笑 | 从下往上打量 | 眼睑压下去 | 一边嘴角往上勾、牙齿刚露一点 | 下巴抬起，说话 |
| 恐惧 | 视线钉住某处 | 呼吸变浅、肩缩起 | 喉头吞一下、脚步退了半步 | 猛回神，说话 |
| 决意 | 闭一下眼 | 呼出一口气、肩沉下 | 手在刀柄上收紧 | 睁眼，说话 |

注意：**「抑制」这一格不能省**。省略抑制就变成「直接演情绪」，又回到面瘫或过火。

---

## 为什么这两招有效（机理推断，非原作者表述）

- `micro expressions` 把「整脸大表情」压回「局部小动作」：模型不需要在大幅形变里保持身份，脸不容易崩，也不容易恒定成一张贴图。
- 部位 + 顺序 给了模型一条**时间线**。只写情绪时，模型只演一个静态状态；写了顺序，它才有「什么时候变」的依据，情绪才能贯穿整段而不是开头一下。

---

## 五条硬纪律（本项目实测，违反必崩）

1. **人像镜不写「呼出的气 / 白气 / 嘴边雾气」**——H3 会画成一大团白雾糊住半张脸。要表现冷，写肩沉、下颌内收、喉结动。
2. **不写「火焰窜高 / 散开 / 升腾」**——火会脱离火盆悬成一团。写高度上限 + 「长在盆里」。
3. **不写「刀身发亮 / 银光」**——会变成光剑一样的白条。写「暗哑旧铁色，只有刃口一线冷光，整块刀身不反白」。
4. **表情要写「维持」**——补一句「这个表情一直维持到最后一个字」，否则中段会自己变脸。
5. **人像特写禁 `extreme low angle` 与 28mm 级广角**——脸会被拉变形，还会和同片其它镜换脸。用 `50 mm` 或 `85 mm`，写 `natural perspective, no wide-angle distortion`。

## 与其它技能的分工

| 管什么 | 用哪个 |
|---|---|
| 六段结构、字段格式、参考标签 | `h3-video-prompt-cn` / `minimax-h3` |
| 光影 / 画质 / 构图 / 动作 / 分镜 / 运镜 的前置设计 | `minimax-h3-preflight` |
| 镜头怎么动 | `h3-camera-motion-lib` / `minimax-h3-camera-moves` |
| 打斗动作 | `minimax-h3-fight` / `minimax-h3-action-moves` |
| **脸怎么演** | **本技能** |

本技能只产出「表情句」，把它填进 `integrated_multimodal_description` 的对应位置，不要另起结构。
